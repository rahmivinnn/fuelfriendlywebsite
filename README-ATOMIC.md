# Atomic Design Implementation

This project uses Atomic Design principles to organize components:

1. **Atoms**: Basic building blocks (buttons, inputs, labels)
2. **Molecules**: Simple combinations of atoms (form fields, cards)
3. **Organisms**: Complex UI sections (navigation bars, forms)
4. **Templates**: Page layouts without specific content
5. **Pages**: Complete pages with real content

## Features

- Dark mode support
- JWT authentication
- Interactive maps
- Fuel cost calculator
- PWA capabilities
- Real-time notifications
- Analytics dashboard
